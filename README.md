# 🤖 AI Automation Chatbot
Streamlit link: https://aiautomationchatbot-1abdullahh.streamlit.app/ 

## 📌 Overview

This AI Automation Chatbot is designed specifically to handle queries related to AI automation.
It focuses only on automation-related topics and does not respond to general or irrelevant questions.

## 🎯 Features

* ✅ Responds only to AI automation-related queries
* 🚫 Ignores irrelevant or off-topic questions
* ⚡ Fast and accurate responses
* 🧠 Smart filtering system based on topic relevance

## 💡 Use Cases

This chatbot is useful for:

* Learning AI automation
* Finding business automation solutions
* Understanding tools like Zapier, Make (Integromat), n8n, etc.

## 🛠️ How It Works

1. The user enters a query
2. The chatbot checks whether the query is related to AI automation
3. If relevant → it provides a proper response
4. If not relevant → it ignores or does not respond

## 🚀 Installation

```bash
git clone https://github.com/your-username/ai-automation-chatbot.git
cd ai-automation-chatbot
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
streamlit run app.py
```

## ⚙️ Configuration

* Requires an OpenAI API key
* Set the environment variable:

```bash
export OPENAI_API_KEY="your_api_key_here"
```

## 📷 Interface

* Simple and clean UI (built with Streamlit)
* Sidebar includes:

  * API key input
  * Model selection
  * System prompt
  * Clear chat option

## ⚠️ Limitations

* Does not answer general knowledge questions
* Limited strictly to AI automation topics
* May ignore or return no response for unrelated queries
